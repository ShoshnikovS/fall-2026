## Теория

Обозначения: `X` матрица признаков (`l x (n+1)`, первый столбец из единиц), `y` вектор ответов из `{0, 1}`, `w` вектор весов.

**Модель.** Линейная комбинация `z = X w` переводится сигмоидой в вероятность положительного класса:

```text
p_hat = sigma(z) = 1 / (1 + e^{-z}).
```

**Функция потерь (правдоподобие).** Для одного объекта правдоподобие `L_i = p_hat_i^{y_i} (1 - p_hat_i)^{1 - y_i}` (при `y_i = 1` остаётся `p_hat_i`, при `y_i = 0` остаётся `1 - p_hat_i`). Объекты независимы, поэтому `L(w) = prod_i L_i`. Логарифм превращает произведение в сумму, а смена знака превращает максимизацию в минимизацию, и получается log-loss:

```text
J(w) = -sum_i [ y_i ln(p_hat_i) + (1 - y_i) ln(1 - p_hat_i) ] -> min.
```

В отличие от RSS, сумма квадратов с сигмоидой невыпукла, а `J(w)` выпукла и замкнутого решения не имеет, поэтому нужен итерационный метод.

**Метод Ньютона-Рафсона.** Функция в окрестности текущей точки приближается параболой (разложение Тейлора второго порядка), и шаг делается в вершину этой параболы:

```text
w_new = w_old - H^{-1} grad J(w_old),
```

где `grad J` градиент, `H` гессиан (матрица вторых производных). Для логистической регрессии

```text
grad J = sum_i (p_hat_i - y_i) x_i = X^T (p_hat - y),
H      = X^T W X,      W = diag(p_hat_i (1 - p_hat_i)).
```

Диагональ `W_ii = p_hat_i (1 - p_hat_i)` максимальна (0.25) при `p_hat_i` около 0.5, то есть у объектов вблизи границы, и близка к нулю там, где модель уверена в ответе (`p_hat` около 0 или 1).

**IRLS (Iteratively Reweighted Least Squares).** Подставим градиент и гессиан в шаг Ньютона:

```text
w_new = w_old + (X^T W X)^{-1} X^T (y - p_hat).
```

Умножим на `X^T W X` слева и учтём `X^T (y - p_hat) = X^T W W^{-1} (y - p_hat)`:

```text
(X^T W X) w_new = X^T W [ X w_old + W^{-1} (y - p_hat) ] = X^T W z,
z = X w_old + W^{-1} (y - p_hat).
```

Это нормальное уравнение МНК с весами `W` для «рабочего ответа» `z`. Поэтому каждый шаг Ньютона это решение взвешенной задачи наименьших квадратов, а `W` и `z` пересчитываются после каждой итерации (отсюда название IRLS). Новые веса получаются тем же шагом, что у метода Ньютона: направления совпадают.

## Реализация

- В коде метки закодированы как `y_i` из `{-1, +1}`, отступ `M_i = y_i <w, x_i>`, `p_hat_i = sigma(<w, x_i>)`. Это эквивалентная запись: `J(w) = sum_i ln(1 + exp(-M_i))`, градиент `-X^T (y * (1 - sigma(M)))` совпадает с `X^T (p_hat - y)` для `y` из `{0, 1}`.
- **Ньютон-Рафсон** (`newton_direction`): система `H delta = -grad J` решается через `np.linalg.solve`, старт `w = 0`, шаг `h = 1`.
- **IRLS** (`irls_direction`): ищется поправка `delta = w_new - w_old` из `(X^T W X) delta = X^T (y - p_hat)`. С `X~ = W^{1/2} X` и ответом `y~ = W^{-1/2} (y - p_hat)` это МНК `X~ delta ~ y~`, решается через `np.linalg.lstsq` (нормальные уравнения не строятся). `irls_glm_direction` та же процедура в записи обобщённой линейной модели для распределения Бернулли (веса `mu (1 - mu)`, ответ `(y - mu) / sqrt(mu (1 - mu))`).
- Численные детали: `sigma` через `scipy.special.expit`, потери через `np.logaddexp`; `p_hat` ограничена отрезком `[1e-12, 1 - 1e-12]`, чтобы веса и ответы были конечны; останов по `||w_new - w_old|| < 1e-10`.
- Реализованы также L2-регуляризация и градиентный спуск с шагом `1/L`, `L = lambda_max(X^T X) / 4`, для сравнения скорости.
