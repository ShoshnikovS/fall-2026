## Теоретическая основа

**Задача.** Бинарная классификация, но модель оценивает вероятность класса: `P(y=+1 | x)`. Слово «регрессия» в названии потому, что моделируется среднее ответа `E[y | x] = P(y=1 | x)`, а класс получается порогом `P >= 0.5`.

**От линейной комбинации к вероятности.** Пусть `p = P(y=+1 | x)` вероятность положительного класса. Линейная комбинация `z = <w, x>` принимает любые значения, а `p` лежит в `[0, 1]`, поэтому `p = z` не подходит. Переход делается в два шага:

1. Шансы (odds) `p / (1 - p)` лежат в `(0, +inf)`: это во сколько раз «да» вероятнее «нет».
2. Логит `logit(p) = ln(p / (1 - p))` лежит в `(-inf, +inf)`. Логит называется функцией связи. Предполагается, что он линеен по признакам: `ln(p / (1 - p)) = <w, x>`.

Решая это равенство относительно `p`, получаем сигмоиду:

```text
p = sigma(z) = 1 / (1 + e^{-z}),    z = <w, x>.
```

Сигмоида монотонно растёт от 0 до 1, `sigma(0) = 0.5` и `sigma(-z) = 1 - sigma(z)`. Поэтому `P(y=+1 | x) = sigma(z)`, `P(y=-1 | x) = sigma(-z)`, и для меток `y` в `{-1, +1}` обе вероятности записываются одной формулой `P(y | x) = sigma(y z) = sigma(M)`, где `M = y <w, x>` отступ. Вес `w_j` показывает, на сколько меняется логарифм шансов при росте признака на единицу, то есть шансы умножаются на `e^{w_j}`.

**Функция потерь из максимума правдоподобия.** Для метки `y` в `{0, 1}` и `mu = sigma(<w, x>)` распределение Бернулли даёт `P(y | x) = mu^y (1 - mu)^{1 - y}`. Объекты выборки независимы, поэтому правдоподобие равно произведению:

```text
L(w) = prod_i mu_i^{y_i} (1 - mu_i)^{1 - y_i}.
```

Принцип максимального правдоподобия: выбираем `w`, при которых наблюдаемая выборка наиболее вероятна. Логарифм монотонен, поэтому максимум `ln L` совпадает с максимумом `L`, а произведение превращается в сумму. Смена знака превращает максимизацию в минимизацию:

```text
-ln L(w) = -sum_i [ y_i ln mu_i + (1 - y_i) ln(1 - mu_i) ] -> min.
```

Эта запись и есть логарифмическая функция потерь (log-loss, перекрёстная энтропия). В обозначениях `y` в `{-1, +1}` она проще. Вероятность правильного ответа равна `sigma(M_i)`, и `-ln sigma(M) = ln(1 + e^{-M})`:

```text
Q(w) = sum_i ln(1 + exp(-M_i)) -> min.
```

Обе записи совпадают: для `y = 1` получается `-ln sigma(z) = ln(1 + e^{-z})`, для `y = 0` получается `-ln(1 - sigma(z)) = ln(1 + e^{z})`, и это то же `ln(1 + e^{-M})` при `M = -z`. Потеря близка к нулю при большом положительном отступе и растёт примерно линейно при отрицательном, а сама функция гладкая и служит заменой негладкого числа ошибок `[M < 0]`.

**Почему не МНК.** Классификатор можно обучить и МНК на метках, но тогда предполагается гауссовский шум с постоянной дисперсией, а у бернуллиевского ответа дисперсия `mu (1 - mu)` зависит от среднего. Оценки МНК выходят за `[0, 1]` и вероятностями не являются.

**Градиент и гессиан** (`sigma_i = sigma(M_i)`, `sigma` применяется поэлементно):

```text
Q'(w)  = -F^T (y * (1 - sigma)),
Q''(w) =  F^T diag(sigma (1 - sigma)) F.
```

Гессиан это сумма положительно полуопределённых матриц ранга 1, поэтому `Q` выпукла и локальный минимум глобален. Замкнутого решения нет, нужен итерационный метод.

**Как минимизировать `Q`.** Условие минимума `Q'(w) = 0` нелинейно по `w`, поэтому решение ищут итерациями: `w := w + h d`, где `d` направление, `h` длина шага. Простейший выбор `d = -Q'(w)` это градиентный спуск. Он использует только наклон `Q`, не знает кривизны, поэтому нужен подбор шага и сходится медленно (линейно).

Метод Ньютона-Рафсона учитывает и кривизну. Для одной переменной это поиск корня производной: `x := x - f'(x) / f''(x)`. В многомерном случае функция в окрестности текущей точки приближается квадратичной (разложение Тейлора второго порядка):

```text
Q(w + delta) ~ Q(w) + Q'(w)^T delta + (1/2) delta^T Q''(w) delta.
```

Минимум этого приближения по `delta` достигается при `Q' + Q'' delta = 0`, откуда `delta = -Q''^{-1} Q'`. Шаг метода Ньютона-Рафсона:

```text
w := w - h Q''^{-1} Q',    h = 1.
```

Градиент задаёт направление, гессиан подбирает длину шага: там, где кривизна велика, шаг короче. Для выпуклой `Q` вблизи минимума метод сходится квадратично (число верных знаков удваивается за итерацию), но на каждой итерации нужно строить гессиан и решать систему размера `(n+1) x (n+1)`.

**IRLS (Iteratively Reweighted Least Squares).** Шаг Ньютона можно записать как задачу взвешенного МНК. Вес объекта `gamma_i = sqrt(sigma_i (1 - sigma_i))`, модифицированный ответ `y~_i = y_i sqrt((1 - sigma_i) / sigma_i)`, `F~ = diag(gamma) F`. Тогда

```text
F~^T F~ = F^T diag(sigma (1 - sigma)) F = Q'',      F~^T y~ = F^T (y (1 - sigma)) = -Q',
```

и шаг `w += (F~^T F~)^{-1} F~^T y~` совпадает с шагом Ньютона: это одна и та же линейная система. После каждой итерации пересчитываются `w`, `sigma_i`, веса и ответы. Веса максимальны у объектов вблизи границы (`sigma` около 0.5) и близки к нулю у уверенно классифицированных.

**Обобщённая линейная модель (GLM).** Задаётся тремя компонентами: распределение ответа из экспоненциального семейства, линейный предиктор `eta = <w, x>` и функция связи `g(E[y]) = eta`. Нормальному распределению соответствует тождественная связь, Бернулли логит, Пуассону логарифм. Логистическая регрессия это GLM с распределением Бернулли и логитом. IRLS в записи GLM (метки 0/1): `gamma_i = sqrt(mu_i (1 - mu_i))`, `y~_i = (y_i - mu_i) / gamma_i`, `mu_i = sigma(<w, x_i>)`.

**Разделимая выборка.** Если классы линейно разделимы, `Q` можно уменьшать, умножая `w` на большое число, и конечного минимума нет. Для таких данных нужна регуляризация `(tau / 2) ||w||^2` (свободный член не штрафуется).

## Реализация

- Ньютон-Рафсон (`newton_direction`): система `Q'' delta = -Q'` решается через `np.linalg.solve`, старт `w = 0`.
- IRLS (`irls_direction`): решение через `np.linalg.lstsq(F~, y~)`, нормальные уравнения не строятся; `irls_glm_direction` реализует запись GLM.
- Численные детали: `sigma` через `scipy.special.expit`, потери через `np.logaddexp`; в IRLS `sigma` ограничена отрезком `[1e-12, 1 - 1e-12]`, чтобы вес и ответ были конечны; останов по `||w^{t+1} - w^t|| < 1e-10`.
- Реализованы также L2-регуляризация и градиентный спуск с шагом `1/L`, `L = lambda_max(F^T F) / 4`, для сравнения скорости.
