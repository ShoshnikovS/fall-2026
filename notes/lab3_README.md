## Реализация

Классификатор `a(x) = sign(<w, x> - w0)`, отступ `M_i = y_i (<w, x_i> - w0)`. Для неразделимой выборки используется мягкий зазор с параметром `C`:

```text
(1/2) ||w||^2 + C sum_i xi_i -> min,   M_i >= 1 - xi_i,  xi_i >= 0.
```

Двойственная задача, которая решается в коде (`scipy.optimize.minimize`, метод SLSQP, аналитический градиент):

```text
(1/2) sum_ij lambda_i lambda_j y_i y_j K(x_i, x_j) - sum_i lambda_i -> min,
sum_i lambda_i y_i = 0,   0 <= lambda_i <= C.
```

Решающее правило: `a(x) = sign( sum_i lambda_i y_i K(x_i, x) - w0 )`.

- **Трюк с ядром:** скалярное произведение `<x, x'>` заменяется ядром `K(x, x')`. Реализованы линейное, полиномиальное `(<x, x'> + 1)^3` и RBF `exp(-gamma ||x - x'||^2)`. Для каждого ядра проверяется неотрицательная определённость матрицы Грама.
- **Опорные объекты** (`lambda_i > 0`) делятся на граничные (`0 < lambda_i < C`, `M_i = 1`) и нарушители (`lambda_i = C`, `M_i < 1`).
- **Свободный член:** `w0` усредняется по граничным опорным объектам. Если их нет (при очень малом `C` все опорные объекты нарушители), из условий KKT берётся середина допустимого отрезка для `w0`.
- **Эталон:** `sklearn.svm.SVC` с теми же `kernel`, `C`, `gamma`.

## Результаты

### Подбор параметров (make_moons)

Сетка `C in {0.1, 1, 10, 100}` x `gamma in {0.05, 0.2, 1, 5}`, 5-fold CV на train, собственный SVM с RBF. Лучшие параметры: `C = 10`, `gamma = 0.2` (CV accuracy 0.905). Тест в выборе параметров не участвовал.

### Решение (make_moons)

### Влияние C и gamma

![Влияние C и gamma](svm_c_gamma.png)

| Параметры (RBF) | Accuracy train | Accuracy test | Опорных |

Малое `C` даёт широкую полосу и недообучение (все 210 объектов нарушители). Большое `gamma` даёт границу, обегающую отдельные точки: accuracy на train 0.986, число опорных векторов растёт до 145, на тесте не лучше, чем при `gamma = 1`.

## Выводы

1. Двойственная задача решена через SLSQP, результат совпал с `sklearn.SVC` на обоих датасетах.
2. Решение определяется только опорными объектами: на make_moons их 18-30% выборки, на Breast Cancer 8-23%.
3. Линейный SVM не справляется с нелинейно разделимыми данными, ядро позволяет строить нелинейную границу.
4. `C` управляет штрафом за нарушения, `gamma` гладкостью границы. На почти линейно разделимых данных (Breast Cancer) линейное ядро не уступает RBF.
