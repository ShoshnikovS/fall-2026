## Теоретическая основа

**Линейный классификатор и отступ.** Объекты `x_i` из `R^n`, метки `y_i` из `{-1, +1}`. Классификатор `a(x) = sign(<w, x> - w0)` задаёт гиперплоскость. Отступ `M_i = y_i (<w, x_i> - w0)` положителен, если объект классифицирован верно, и растёт с удалением от границы.

**Идея SVM.** Среди всех разделяющих гиперплоскостей выбирается та, что максимально удалена от обоих классов. Расстояние от точки `x` до гиперплоскости `<w, x> - w0 = 0` равно `|<w, x> - w0| / ||w||`. Масштаб `(w, w0)` фиксируют так, чтобы у ближайших к границе объектов `M = 1`: тогда они находятся на расстоянии `1 / ||w||` от границы, а границы полосы `<w, x> - w0 = +-1`. Ширина полосы `2 / ||w||`, поэтому максимизация зазора равносильна минимизации `||w||` (удобнее `(1/2) ||w||^2`, это гладкая выпуклая функция).

**Жёсткий зазор** (выборка линейно разделима):

```text
(1/2) ||w||^2 -> min,   M_i >= 1.
```

**Мягкий зазор** (разделимости нет). Вводятся штрафы `xi_i >= 0` за нарушение отступа, `C` задаёт компромисс между шириной полосы и нарушениями:

```text
(1/2) ||w||^2 + C sum_i xi_i -> min,   M_i >= 1 - xi_i,  xi_i >= 0.
```

Эквивалентная запись `(1/2)||w||^2 + C sum_i (1 - M_i)_+`: функция потерь `(1 - M)_+` называется hinge loss, она оценивает сверху число ошибок `[M < 0]`, а `(1/2)||w||^2` играет роль L2-регуляризации. Большой `C` даёт узкую полосу и подгонку под данные, малый `C` широкую полосу и много нарушителей.

**Двойственная задача.** Задача мягкого зазора это выпуклая задача квадратичного программирования с линейными ограничениями. Для ограничений вводятся множители Лагранжа `lambda_i >= 0` (на `M_i >= 1 - xi_i`) и `mu_i >= 0` (на `xi_i >= 0`):

```text
L = (1/2) ||w||^2 + C sum_i xi_i - sum_i lambda_i (M_i - 1 + xi_i) - sum_i mu_i xi_i.
```

В седловой точке производные `L` по `w`, `w0`, `xi_i` равны нулю:

```text
dL/dw  = 0  =>  w = sum_i lambda_i y_i x_i,
dL/dw0 = 0  =>  sum_i lambda_i y_i = 0,
dL/dxi = 0  =>  lambda_i + mu_i = C,  то есть 0 <= lambda_i <= C.
```

Подстановка этих равенств в `L` исключает `w`, `w0` и `xi` и даёт двойственную задачу по `lambda`, которая решается в коде:

```text
(1/2) sum_ij lambda_i lambda_j y_i y_j <x_i, x_j> - sum_i lambda_i -> min,
sum_i lambda_i y_i = 0,   0 <= lambda_i <= C.
```

**Типы объектов (условия дополняющей нежёсткости):**

```text
lambda_i = 0        =>  M_i >= 1             периферийный объект, на решение не влияет
0 < lambda_i < C    =>  M_i = 1,  xi_i = 0   опорный граничный (лежит на границе полосы)
lambda_i = C        =>  M_i <= 1, xi_i > 0   опорный нарушитель (внутри полосы или за границей)
```

Опорными называются объекты с `lambda_i > 0`: только они входят в сумму для `w`. Свободный член находится по граничным объектам: `w0 = <w, x_i> - y_i`.

**Трюк с ядром.** В двойственной задаче и в решающем правиле объекты входят только через скалярные произведения, поэтому `<x, x'>` заменяется ядром `K(x, x') = <psi(x), psi(x')>` для некоторого спрямляющего отображения `psi`. Гиперплоскость строится в спрямляющем пространстве без явного вычисления `psi`:

```text
a(x) = sign( sum_i lambda_i y_i K(x_i, x) - w0 ).
```

Ядро должно быть симметричным и неотрицательно определённым: матрица Грама `[K(x_i, x_j)]` положительно полуопределена (условие Мерсера), иначе двойственная задача перестаёт быть выпуклой.

Реализованные ядра:

```text
линейное:        K(x, x') = <x, x'>
полиномиальное:  K(x, x') = (<x, x'> + 1)^3
RBF:             K(x, x') = exp(-gamma ||x - x'||^2)
```

`gamma` задаёт радиус влияния объекта (большой `gamma` даёт извилистую границу и переобучение).

Новые ядра можно строить из допустимых `K1`, `K2`: подойдут `a K1` при `a > 0`, `K1 + K2`, `K1 * K2`, `exp(K1)`. Например, полиномиальное ядро это степень суммы линейного ядра и константы, а RBF раскладывается как `exp(-gamma ||x||^2) exp(-gamma ||x'||^2) exp(2 gamma <x, x'>)`.

**Регуляризация.** Слагаемое `(1/2) ||w||^2` это L2-регуляризация: она ограничивает веса и расширяет полосу. Параметр `C` задаёт баланс с потерями на нарушениях (`C` ведёт себя как обратная сила регуляризации). Для сравнения, L1-штраф `sum_j |w_j|` обнуляет часть весов и тем самым отбирает признаки, а L2 только уменьшает веса. В работе используется L2, как в классической постановке SVM.

## Реализация

`DualSVM` (`source/svm_dual.py`):

- `scipy.optimize.minimize(method="SLSQP")` минимизирует `(1/2) lambda^T Q lambda - sum lambda`, `Q_ij = y_i y_j K(x_i, x_j)`, с аналитическим градиентом, границами `[0, C]` и ограничением `lambda^T y = 0`;
- значения `lambda` с точностью `1e-6 C` округляются до `0` и `C`;
- `w0` усредняется по граничным опорным объектам; если их нет (при очень малом `C` все опорные объекты нарушители), берётся середина допустимого из условий KKT отрезка;
- для проверки допустимости ядра считается минимальное собственное значение матрицы Грама;
- эталон `sklearn.svm.SVC` с теми же `kernel`, `C`, `gamma` используется только для сравнения.

## Выводы

1. Двойственная задача решена через SLSQP, результат совпал с `sklearn.SVC` на обоих датасетах.
2. Решение определяется только опорными объектами: на make_moons их 18-30% выборки, на Breast Cancer 8-23%.
3. Линейный SVM не справляется с нелинейно разделимыми данными, ядро позволяет строить нелинейную границу.
4. `C` управляет штрафом за нарушения, `gamma` гладкостью границы. На почти линейно разделимых данных (Breast Cancer) линейное ядро не уступает RBF.
