## Реализация

Метки `y_i in {-1, +1}`, отступ `M_i = y_i <w, x_i>`, `sigma_i = sigma(M_i)`. Модель `P(y=+1 | x) = sigma(<w, x>)`, максимум правдоподобия для распределения Бернулли даёт функционал

```text
Q(w) = sum_i ln(1 + exp(-M_i)) -> min,
Q'(w)  = -F^T (y * (1 - sigma)),
Q''(w) =  F^T diag(sigma (1 - sigma)) F.
```

**Ньютон-Рафсон:** `w := w - Q''^{-1} Q'`, старт `w = 0`, система решается через `np.linalg.solve`.

**IRLS:** веса объектов `gamma_i = sqrt(sigma_i (1 - sigma_i))`, модифицированные ответы `y~_i = y_i sqrt((1 - sigma_i)/sigma_i)`. Для `F~ = diag(gamma) F` выполнено `F~^T F~ = Q''` и `F~^T y~ = -Q'`, поэтому шаг взвешенного МНК `w += (F~^T F~)^{-1} F~^T y~` совпадает с шагом Ньютона. Решение через `np.linalg.lstsq(F~, y~)`.

**IRLS в записи GLM** (метки 0/1): для распределения Бернулли `gamma_i = sqrt(mu_i (1 - mu_i))`, `y~_i = (y_i - mu_i)/gamma_i`.

Численные детали: `sigma` считается через `scipy.special.expit`, потери через `np.logaddexp`; в IRLS `sigma` ограничена отрезком `[1e-12, 1 - 1e-12]`, чтобы вес и ответ были конечны; останов по `||w^{t+1} - w^t|| < 1e-10`. Реализована также L2-регуляризация (свободный член не штрафуется) и градиентный спуск с шагом `1/L` для сравнения скорости.

### Ньютон и IRLS

Траектории `w^t` метода Ньютона, IRLS и IRLS в записи GLM совпадают на каждой итерации (максимальное расхождение не больше 3e-15), все три останавливаются на 7 итерации. IRLS из МНК-приближения сходится за 6 итераций к тому же решению. Веса `gamma_i^2` не превосходят 0.25 и максимальны у объектов вблизи границы (`M` около 0), у уверенно классифицированных объектов (`M` около 4.5) около 0.01.

### Сравнение с эталоном (`penalty=None`)

| solver | max‖Δw‖ | max‖ΔP‖ на тесте | совпадение предсказаний |
|---|---|---|---|
| `newton-cholesky` | 2.2e-16 | 2.2e-16 | 100% |
| `lbfgs` (tol=1e-12) | 4.1e-08 | 3.5e-08 | 100% |

`Q(w_own) = Q(w_sklearn) = 246.80711705`. `newton-cholesky` реализует тот же метод Ньютона, поэтому совпадение до машинной точности; `lbfgs` квазиньютоновский, отсюда расхождение порядка 1e-8. С регуляризацией `tau = 1` соответствует `C = 1` в sklearn, расхождение Ньютона и IRLS не больше 2.2e-16.
